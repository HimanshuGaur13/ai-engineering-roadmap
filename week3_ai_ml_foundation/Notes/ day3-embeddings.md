1. Embeddings - Numerical representation of text that captures meaning.
   Puppy -  [0.25, 0.57, -0.10, ...]

2. Vector
   Vector = Numerical representation of information.

3. Similarity Search = Finding vectors closest to a query vector.

4. Cosine Similarity - Cosine Similarity measures how close two vectors are.

5. Semantic Search = Search by meaning

6. Embedding Generation
   Real embeddings are generated by models.
   Popular models:OpenAI Embeddings, Sentence Transformers, BGE, E5

7. RAG: Document → Chunk →  Embedding → Vector DB → Retrieval → LLM
